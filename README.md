# DearData100
DearData100 creative coding project:
- this project explores my phone usage by recording the reasons I unlock my phone. Each unlock is treated as a data point that is then categorised according to its main purpose.
- there are a total of 104 data entries
- there are a total of 16 different reasons, grouped into 4 categories
- messaging = messages, whatsapp, discord
- social media = snapchat, instagram, tiktok
- productivity = alarm, phone, maps, deliveroo
- entertainment = spotify, reading, minecraft, clash royal, roblox
